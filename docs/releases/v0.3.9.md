# DevFlow v0.3.9

This documentation release updates the developer CLI walkthrough and shared
guides to match the implemented eleven-skill Codex/Claude package, marketplace,
initialization, host integration and authorized PR delivery flow.

- Corrects stale installation and platform claims while preserving the limits of
  current-release end-to-end validation.
- Uses consistent greeting specification paths in examples and skill guidance.
- Adds a [documentation index](../README.md), labels retained historical designs,
  plans and audits, and removes superseded execution notes and scratch ledgers.
- Keeps the [setup and usage guide](../setup-and-usage.md) as the primary user
  reference; direct helper setup remains an optional developer reference.

No helper command, journal schema or runtime behavior changed. Package manifests
and the version assertion advance together to v0.3.9. The documentation cleanup
received independent review; its delivery-authorization ordering finding was
corrected before release preparation.

The documentation audit checked local links, example JSON, skill metadata and
documented command syntax. The full Python suite passed 471 tests with one
platform-specific skip on macOS. Claude marketplace validation and an isolated
local v0.3.9 installation passed, with eleven skills and seven installed-hook
behavior tests. See the [validation report](../cross-host-validation.md)
for package installation evidence and remaining end-to-end host checks. Native
Windows and WSL2 support remain unreleased; see the
[platform matrix](../windows-validation.md).
