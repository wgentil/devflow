# DevFlow v0.3.7

The `ux-reviewer` skill now separates observed defects from requirement gaps,
risks, and questions. Findings use severity based on user-task impact, and a
worked report shows how to state evidence and coverage limits. The skill and
guide diagrams, setup guide, and example index reflect this behavior.

The update was reviewed through the approved [Autowork design](../superpowers/specs/2026-10-13-ux-reviewer-autowork-design.md)
and [plan](../superpowers/plans/2026-10-13-ux-reviewer-autowork.md). No helper
command or formal review gate changed. Native Windows and WSL2 remain outside
the supported host matrix; see the [validation matrix](../windows-validation.md).
