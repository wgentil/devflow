# DevFlow v0.3.1

This bugfix lets a Claude or Codex session attach to a new active run after its
previous run was delivered or discarded. The new attachment retires the old
binding and task mappings in one journal event. Host locators and task indexes
are rebuilt, including across project directories and on an exact attach retry.
Running native work or a claimed repair cycle still blocks ownership changes.

The package also documents the Codex CLI GitHub marketplace installation path.
An isolated install of the previous 0.3.0 release succeeded. Validation for
this package includes 396 passing Python tests, Claude marketplace validation,
and isolated GitHub installs in both Claude Code and Codex CLI that reported
enabled version 0.3.1. See [cross-host validation](../cross-host-validation.md).
