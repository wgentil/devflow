# DevFlow v0.3.2

New projects now get a first-use ground interview before repository-backed feature
planning and work. The visible `docs/devflow-ground-interview.json` records 19
product, technical, quality, delivery and team topics. The agent reuses repository
and inherited organization evidence, asks for missing decisions and revisits the
baseline when project choices change. Material deferrals block advancement. The
helper validates the recorded inventory; the agent remains responsible for the
substance and materiality of decisions. Existing project manifests without an
interview declaration retain their prior behavior.

`setup ground-check --project-dir` reports readiness, missing topics and material
deferrals. The setup guide, skill instructions, diagrams and examples describe the
new checkpoint. Validation: 402 Python tests passed on the versioned package;
Claude marketplace validation and an isolated local install reported enabled
version 0.3.2.
