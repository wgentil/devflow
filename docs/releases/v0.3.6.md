# DevFlow v0.3.6

Adds the `ux-reviewer` skill for reviewing live interfaces, designs,
screenshots, and UX requirements. It reports prioritized findings with
observable evidence, user impact, and suggested changes. It can supply UX
evidence to a formal `review-work` package, but does not create an independent
review verdict or add a helper command.

The skill and usage guide include review and reporting diagrams. The setup and
skill indexes now explain when to use it. Native Windows and WSL2 remain outside
the supported host matrix; see the [validation matrix](../windows-validation.md).
