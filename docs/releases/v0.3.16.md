# DevFlow v0.3.16

Archive-backed control storage addresses [issue #5](https://github.com/wgentil/devflow/issues/5).

- New roots use indexed storage format 2; existing legacy roots remain unchanged
  until explicit verified conversion. Logical workflow schema remains 1.
- Complete terminal history and review payloads remain in verified immutable
  archives. Routine current work uses selected indexed views and context shards.
- Manual compaction, GC, complete backups, full verification and stopped-owner
  pin reconciliation are available. Inspection/dry-run is the default; no history
  purge, automatic legacy conversion or automatic GC is enabled.
- Independent namespace/entity/operation/document witnesses fail closed on missing
  or corrupt discovery metadata. Exact archived operation IDs remain reserved.
- Backup output belongs to its exact request; interrupted public recovery and
  native/interactive dispatch retain source, approval and ownership checks.

The implementation review corrected seven required findings with RED-to-GREEN
regressions. Its 920-test suite and all nine native CI jobs passed before release
versioning; exact v0.3.16 validation is recorded separately in the
[release report](v0.3.16-validation.md). The [implementation report](../superpowers/reviews/2026-10-26-control-state-compaction.md)
retains all decisions, costs, source-bound evidence and the deferred SQL
instrumentation limitation.

A controlled 100 MiB review corpus retains complete logical/audit parity with
3.8 KiB of hot logical payload. Backups and archives remain retained; total disk
use can grow. SQL counters measure transaction bodies, not connection/commit work.
No production project was converted or garbage collected. Signed-in host/model
execution remains unverified by automated installation and script tests.
