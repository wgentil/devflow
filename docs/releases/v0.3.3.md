# DevFlow v0.3.3

This release adds cross-platform file locks and native-process transport, safer
Windows process-tree cleanup, unambiguous Git pathname handling, and stable
governing-document comparison across Windows checkout line endings. Claude hooks
now use a shell-free command. The full 421-test Python suite passed on macOS,
Ubuntu, and native Windows; Windows CI also installed the Claude plugin and ran
seven hook tests against that installed copy.

Native Windows and WSL2 are still **outside the supported host matrix**. Live
authenticated Claude and Codex workers, live hook dispatch, WSL2 Linux-filesystem
behavior, and cross-OS handoff remain unverified. See the
[Windows validation matrix](../windows-validation.md) for precise evidence and
open gates. Users choose when to upgrade each host; DevFlow enforces exact
installed-release parity during handoff.
