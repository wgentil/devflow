# DevFlow v0.3.13

This patch fixes native Windows compatibility across document/request encoding,
CLI and hook protocols, installed host launching, and process cleanup.

- Use explicit UTF-8 for owned text and machine-readable streams under ordinary
  Windows locales. Optional diagnostics cannot mask a committed operation.
- Preserve raw command-log/artifact bytes and CRLF; decode structured reports
  strictly. Record successful output-byte measurements after the write succeeds.
- Launch native executables or validated npm entry points without batch-text
  interpolation. Confirm Windows job-member exit before replacement work starts.
- Preserve exact package identity and routed-reference byte budgets through Git
  checkout newline conversion, while retaining binary bytes and existing limits.
- Collect complete native suites and separate actual installation/startup,
  hook-script behavior and authenticated acceptance. Keep onboarding guided by
  the harness, with detailed commands in optional maintainer references.

Windows Python 3.11.9/3.15.1. Windows skipped only the POSIX newline-filename
case; Unix skipped three native-Windows-only cases. Both Windows legacy CP1252
checks passed 22 tests. Actual isolated Codex/Claude installation, startup,
Codex RPC/cleanup and twelve installed hook-script tests passed. Independent
review findings were reproduced and corrected with RED→GREEN regressions.
