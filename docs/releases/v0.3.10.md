# DevFlow v0.3.10

This release adds bounded context preparation and shared task model/effort routing
for Claude and Codex, with a simpler guided entry point.

- Adds a minimal [quick start](../quick-start.md). The harness guides subsequent
  work; users do not need to learn skill names or helper syntax.
- Splits detailed guidance into registered sections with enforced byte budgets,
  content-bound caches, scoped checkpoints and complete task-context recovery.
- Adds bounded Python lifecycle hooks, verification failure digests, focused
  validation plans and context measurements without inferred token/cost savings.
- Renders requirement headings separately from plain paragraph descriptions.
- Adds versioned task facts, conservative routing profiles, path-specific host
  controls, immutable routing evidence and explicitly authorized bounded escalation.
- Preserves operational retries after escalation and blocks stale model suitability
  or contradictory host evidence before dispatch.
- Adds scoped worker outcomes, prepared interactive requests, offline routing
  comparisons and journal-attributed routing statistics.

No new validated provider mappings or production interactive bridge ship. Prepared
requests do not start workers. Claude effort remains unobservable and cannot
satisfy strict effort compliance. Paid/live evaluation and current-release
end-to-end host workflows remain unverified; see [validation limits](../cross-host-validation.md).

The implementation received independent review; four Important findings were
corrected with reproducing regression tests. One minor remains: malformed routing
evaluation input can raise a Python exception instead of a structured diagnostic,
without dispatching or promoting a model. See the
[routing verification report](../superpowers/reviews/2026-10-19-cross-host-task-routing.md).

Release validation: Claude marketplace validation passed with the existing
root-`CLAUDE.md` context warning. An isolated local v0.3.10 installation exposed
all eleven skills and passed all ten installed-hook behavior tests. The full
implementation suite passed 590 tests with one platform-specific skip; package
metadata, documentation links/selectors and byte-budget checks passed.
