# DevFlow v0.3.5

After DevFlow records a completed build delivery, its coordinating agent now
asks once whether the user wants to update the [DevFlow Codex site](https://devflow-field-guide.waygent.chatgpt.site/)
with that build. The offer follows both direct delivery and a ready-to-merge
pull request, including documentation-only builds. Declining or leaving the
offer unanswered does not affect delivery; site updates require a separate yes
and are not automatic.

The workflow diagram, skill guide, setup guide and example document the prompt.
No helper command or journal contract changed. Native Windows and WSL2 remain
outside the supported host matrix; see the [validation matrix](../windows-validation.md).
